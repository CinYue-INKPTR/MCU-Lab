# OLED

使用 IIC 或 SPI 通信协议的 SSD1306 屏幕驱动。

适配 128x64、128x32、72x40 分辨率。（128x32 规格受硬件接口限制，仅可用 IIC 协议）

## 代码结构

### INKPTR_OLEDiic.c

| Part | 名称 | 说明 | 移植注意 |
| :-: | :-- | :-- | :-- |
| 1 | 库引用 | 引入宏定义参数和标准外设接口 | 库名 |
| 2 | 显示参数 | OLED 型号参数表和初始化命令表 | - |
| 3 | 边界检查函数 | 检查页、列地址值是否超出当前型号范围 | - |
| 4 | 数据头封装 | 封装命令起始和数据起始的 I2C 时序 | IIC 时序函数名 |
| 5 | 功能函数 | 显示设置、填充、绘图、滚屏函数 | IIC 时序函数名 |
| 6 | 初始化函数 | 初始化 OLED 显示 | 初始化接口函数名，各参数名 |

### INKPTR_OLEDiic.h

| Part | 名称 | 说明 | 移植注意 |
| :-: | :-- | :-- | :-- |
| 1 | 库引用、固定参数宏定义、枚举与接口声明 | 引用变量类型定义，提供本代码模块的函数接口 | 库名 |
| 2 | 可调参数宏定义 | 屏幕分辨率 | 选择对应的屏幕分辨率 |
