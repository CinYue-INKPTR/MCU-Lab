# SoftSPI

使用片选线 CS、时钟线 SCK、数据线 MOSI 和 MISO 进行通信的协议，其中 CS、SCK、MOSI 为推挽输出模式，MISO 为浮空输入模式。

适配 4 中工作模式。

<br>

## 代码结构

### INKPTR_SoftSPI.c

| Part | 名称 | 说明 | 移植注意 |
| :-: | :-- | :-- | :-- |
| 1 | 库引用 | 引入宏定义参数和标准外设接口 | 库名 |
| 2 | 延时函数 | CS、SCK 电平变化后的延时，用于控制 SPI 的通信速度 | 通信速率延时 |
| 3 | 引脚封装 | 引脚电平操作与读取的封装，用于时序模块的调用 | 操作引脚的接口函数名 |
| 4 | 通信时序模块 | 实现四种 SPI 模式的字节交换和 SPI 起始、停止时序 | - |
| 5 | 初始化函数 | 用于初始化软件 SPI 所需的引脚 | 初始化接口函数名，各参数名 |

### INKPTR_SoftSPI.h

| Part | 名称 | 说明 | 移植注意 |
| :-: | :-- | :-- | :-- |
| 1 | 库引用与接口声明 | 引用变量类型定义，提供本代码模块的函数接口 | 库名 |
| 2 | 可调参数宏定义 | 设置 GPIO 时钟、速度、端口、引脚及 SPI 工作模式 | 根据需求调整 SPI 要使用的引脚及其属性、设置 SPI 工作模式（0 ~ 3） |
